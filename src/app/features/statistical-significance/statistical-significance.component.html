Methodology Notes

  • Paired t-test compares mean CV-fold scores across the same 10 folds, controlling for fold-level variance.
  • McNemar test operates on the hold-out test set contingency table of discordant predictions between the two models.
  • Both tests use α = 0.05; reported p-values far exceed the significance threshold.
  • Effect size (Cohen's d) for the paired comparison is large (d > 1.5), indicating practical significance.
